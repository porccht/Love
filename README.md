## 🚀 Hướng Dẫn Cài Đặt & Sử Dụng

1. **Tải về kịch bản:**
   Lưu toàn bộ mã nguồn vào một file duy nhất đặt tên là `index.html`.

2. **Khởi chạy:**
   Click đúp trực tiếp vào file `index.html` để mở trên bất kỳ trình duyệt nào (Chrome, Edge, Safari, Firefox) hoặc deploy lên GitHub Pages / Vercel / Render.

3. **Mở quản trị (Admin):**
   - Bấm vào biểu tượng ⚙️ ở góc trên bên phải.
   - Nhập mã **PIN** quản trị để mở khóa quyền chỉnh sửa.

---
## ✨ Tính Năng Nổi Bật

- ⏳ **Đếm thời gian thời gian thực:** Cập nhật chính xác từng **Ngày, Giờ, Phút, Giây** bên nhau.
- 🎨 **Giao diện Liquid Glassmorphism:** Hiệu ứng kính mờ (Backdrop Filter), hiệu ứng đèn Neon phản chiếu quyến rũ trên nền Dark Mode mượt mà.
- 🎆 **Hiệu ứng Trái Tim Bay (Canvas):** Particle trái tim ngọt ngào bay lơ lửng ngẫu nhiên ở nền trang web.
- 📅 **Lịch Thông Điệp Hằng Ngày (Daily Quote):** Tự động chuyển đổi các câu nói hay, ý nghĩa về tình yêu mỗi khi qua ngày mới (như tờ lịch tình yêu).
- 🔒 **Chế độ Bảo Vệ (Admin Lock):** Khóa quyền chỉnh sửa thông tin giao diện. Chỉ khi nhập đúng mã **PIN** mới có thể tùy chỉnh ngày bắt đầu, tên, avatar hoặc câu nói.
- 💾 **Lưu dữ liệu tự động (LocalStorage):** Mọi tùy chỉnh cá nhân đều được lưu trên trình duyệt, không sợ mất khi F5 hoặc tải lại trang.
